🌤️ Explorador de Clima
App web para consultar el clima actual de cualquier ciudad del mundo.

🔗 Demo: https://scorpwik.github.io/ClimaConexionAPI/

¿Qué hace?
Busca el clima de una ciudad usando la API de OpenWeatherMap
Muestra temperatura, humedad, viento y presión
Maneja estados de carga y error con botón de reintento
Guarda las últimas 5 búsquedas exitosas como accesos rápidos
Tecnologías
HTML · CSS · JavaScript (fetch / async-await)

API
OpenWeatherMap — requiere API Key gratuita.
